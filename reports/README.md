# Reports

This folder contains progress reports documenting the development of the AI chatbot over the 6-week internship.

## Contents
- Weekly progress reports — summarizing tasks completed, challenges faced, and next steps for each week
- Final report — a comprehensive summary of the project, covering architecture, tech stack, implementation, testing, and deployment

## Suggested Report Structure
Each weekly report should briefly cover:
1. **Tasks completed** this week
2. **Challenges faced** and how they were resolved
3. **Plan for next week**

## Final Report Should Include
- Project overview and objectives
- System architecture and tech stack
- NLP pipeline implementation details
- UI/UX design decisions
- Testing approach (see `data/` folder for test cases used)
- Deployment process (see `deployment/` folder)
- Screenshots/demo of the working chatbot
- Learnings and conclusion
